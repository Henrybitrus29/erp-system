# Enterprise Resource Planning (ERP) System
Developed by Chidama Tech Partners LLC

### How to Run:
1. Move the `erp` folder into your local XAMPP `htdocs` directory (`C:\xampp\htdocs\`).
2. Start Apache and MySQL via XAMPP.
3. Open phpMyAdmin (`http://localhost/phpmyadmin/`), create a database named `erp_system`, and import the provided `erp_system_backup.sql` file.
4. Open your browser and go to: `http://localhost/erp/index.php`
5. Login using: **admin** / **admin123**
